# 聆序开发版本测试

按用户要求，先交付代码侧收尾后的开发包，暂停自动开发，由用户测试后继续。
这不表示完整计划或正式 Release 验收已经完成。

## 安装与入口

ColorOS 16 手机通常使用 android-arm64 APK；ARMv7 设备使用 android-arm。
Windows 根据 CPU 选择 x64 / ARM64 安装程序。Android 更新沿用同一包名和签名。
下载 APK 后打开，按手机提示安装即可；本次测试无需把手机连接到开发服务器。
播放器内嵌 TuneWeave，默认不需要填写远程服务地址。

首页右上角进入“账号与服务”，登录所需平台。搜索框右侧选择浏览平台；
“自动选源”控制播放平台偏好。宽屏左侧与窄屏抽屉都有设置入口。
请使用自己的设备登录，不要将 Cookie 或令牌写进问题报告。

## 第一轮优先测试

| 项目 | 操作与预期 | 需要的环境 |
| --- | --- | --- |
| 基本播放 | 搜索并播放多首歌曲，暂停、继续、切歌、拖动进度，核对声音与实际歌词 | Windows / Android |
| 混合队列 | 本地、在线与云盘歌曲混排；重复加入同一首，检查顺序与独立队列项 | 设备 + 云盘账号 |
| 回退选源 | 播放原平台不可用的曲目，尝试自动选源及指定其他平台；只有完整解析无源才置灰 | 设备 |
| 缓存 | 完整播放/缓存后断网尝试；检查容量、清空缓存后容量下降 | 设备 |
| 导出 | 下载一首完整歌曲，确认文件可播放；取消保存；Windows 同名覆盖；Android 系统保存界面 | 设备 |
| 后台与焦点 | 锁屏、切到其他应用、用系统媒体控制、拔耳机；与其他播放应用争用音频焦点 | Android 真机 |
| 云盘 | 读取、搜索、播放、歌词、下载；用一份小文件测试上传与删除；中断传输后检查状态 | 真实网易云账号 |
| 播放上报 | 确认默认启用；播放、暂停、拖动后检查平台实际记录，切换账号后不能串账号上报 | 真实网易云账号 |
| 平台歌单 | 新建、重命名、加歌、移除、删除；核对平台端实际变化 | 真实平台账号 |

缓存、上传、上报的服务器 mock 测试已经覆盖若干失败路径，但不能代替上述真实账号测试。
请逐项记录“通过 / 失败 / 未测试”。失败时给出设备型号、系统版本、操作步骤、歌曲名/来源、
现象和是否必现；可以提供截图，但不要提供账号凭据。

## 最后处理的厂商项

ColorOS 16 流体云目前只有标准 MediaSession 基线，专属控制和歌词接入尚未完成。
测试时记录系统是否显示媒体入口、能否控制播放，以及歌词是否可见；结果用于后续厂商适配，
不能预先把这些项目标为通过。

HyperOS 也先验证标准媒体会话；专属超级岛未实现，属于后续尽力适配项。

## 正式发布门槛

四架构构建与下载校验是开发交付检查。目标设备安装、声音、后台、账号和 ColorOS 验收仍未完成。
播放库的完整对应源码核对也保持独立待办，详见 RUNTIME_AUDIT.md。
